01 — The Idea

LLM inference can repeatedly process shared prompt prefixes, creating opportunities for redundant computation.

CacheRag explores how cache-aware request routing and prefix caching can make inference systems more efficient.

02 — The Engineering
COMPONENT	OBJECTIVE
⚡ Prefix Caching	Reuse previously computed shared prompt prefixes
🧭 Cache-aware Routing	Make routing decisions with cache locality in mind
🧠 Inference Efficiency	Explore reducing redundant computation
📊 Performance Evaluation	Investigate latency, throughput, and cache utilization
